# Weather App

A simple weather application built using **HTML**, **CSS**, and **JavaScript**.  
Users can select a city and instantly view the weather.  
The project also includes a scroll-to-top button that becomes visible after scrolling more than half of the viewport.

## Features
- Weather updates based on selected city  
- Added Arad, Sibiu, Iasi, Timisoara, Bucuresti.
- Smooth scroll-to-top button  
- Simple and responsive layout
